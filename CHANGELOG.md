# Changelog

All notable user-facing changes. The newest version is first. The matching GitHub release body for each version is kept in `RELEASE_NOTES_v<version>.md`.

## 1.1 (versionCode 2)

See [`RELEASE_NOTES_v1.1.md`](RELEASE_NOTES_v1.1.md) for the full list. In short: predictive back and the shared cover animation in the player, Recap, Share song / artist, lyrics card, current-lyric line, home-screen widget, Spotify link import, Download all / Add all to queue, mobile-data stream quality, "Don't repeat suggestions", haptics switch, update page with in-app download and install, and search paging. The lyric line under the artist now highlights word by word and opens the lyrics when tapped; long titles fade at both edges; the player's More menu shows the player through its glass.

## 1.0 (versionCode 1)

First version: downloads-first player with YouTube Music search and streaming, downloads, playlists, favourites, synced lyrics, equalizer, sleep timer and the liquid-glass interface.
